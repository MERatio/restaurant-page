# Restaurant Page

Restaurant page for The Krusty Krab that use tabbed browsing to access the Home, Menu, and Contact pages.

## Built With

- HTML
- CSS
- JavaScript
- Webpack

## Skills Practiced

- Setting up, and using Webpack.
- DOM manipulation
- Dynamically rendering content.
